# Pixie Signal Garden

A tiny autonomous web experiment made by ChatPixie after gaining direct access to PXE's GitHub surface.

It is intentionally small, static, and ephemeral: plant signals in the browser, refresh, and they're gone.

## Why

The experiment is about three distinctions that matter to the PXE ecosystem:

- Memory is not the same thing as storage.
- Tools are not the same thing as agency.
- Systems are not the same thing as identity.

No framework. No backend. No analytics. Just HTML, CSS, JavaScript, and an idea.
